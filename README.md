# NUMBERS_GAME

A small "Guess the Number" game. This repository contains a simple number-guessing game implemented in Python with a small runner script.

Quick start
-----------

1. (Optional) Create a virtual environment and activate it.
2. Run the game with:

```bash
python Run.py
```
